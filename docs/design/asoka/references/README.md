# Logo escolhida — Asoka

Kevin forneceu e escolheu esta marca em 08/10/2026, autorizando recorte, escala e aplicação. Depois de receber a prévia, autorizou commit, push e publicação da versão.

- `1.png`: símbolo grafite.
- `2.png`: nome completo grafite.
- `3.png`: símbolo claro.
- `4.png`: nome completo claro.

Aplicação local: nome completo grafite sobre as superfícies claras existentes, sem degradê; símbolo grafite centralizado em placa clara para `icon.png` (512px) e `apple-icon.png` (180px). Os azuis e degradês da interface permanecem. Os arquivos originais são transparentes e foram preservados integralmente; só as cópias de produção recebem recorte das margens e remoção de metadados.

Reprodução: `node scripts/generate-asoka-brand.mjs`, usando Sharp já disponível no projeto. Nenhuma geração por IA nem redesenho da marca. Assets antigos preservados para recuperação, sem consumo pela interface atual. O gerador legado `scripts/generate-brand-icons.py` pertence à Zucco e não deve ser executado para a identidade atual.

Originais movidos da pasta temporária `Logo Asoka/` da raiz para esta pasta, preservando os quatro arquivos integralmente. Exportações quadradas de 1024px para foto de perfil ficam em `../exports/`: `asoka-whatsapp-logo-1024.png` (nome completo, margem segura para recorte circular) e `asoka-whatsapp-symbol-1024.png` (símbolo isolado).
